# cb-statement

Partner-layer **cb-statement** block (Ralph Lauren × Tour de France). Purpose: one display-size line with an optional attribution, shown as a title card between content sections.

## Authoring (Document Authoring)

Model: `standalone`

Single block table with one cell: the statement (a heading, or a paragraph that is promoted to an h2), then an optional attribution paragraph. Put the block in its own section and set the section metadata style to `center, black`.

## Supported variations

No variations. The ground comes from the section style (`black` for the immersive look; any core section style works).
